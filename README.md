# 🚀 Cris-Launcher

> **Tu Launcher, Tu Estilo**

Repositorio oficial del proyecto **Cris Launcher**, un launcher personalizado desarrollado en **Sketchware Pro**. Diseñado para ser ligero, personalizable y único.

---

## ✨ Características
* **Tarjeta de Música Personalizada:** Widget reproductor en tiempo real que se conecta con tus apps de música activas mediante permisos de notificaciones.
* **Ligero y Rápido:** Desarrollado completamente en Sketchware Pro y optimizado para ofrecer un buen rendimiento.
* **Estilo Personalizable:** Interfaz limpia pensada para darte el control total sobre la pantalla de inicio.
